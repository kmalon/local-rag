Spring Boot 3 app (Ports & Adapters). Ingests local files/docs via REST API, creates embeddings (Spring AI + OpenAI), stores to PostgreSQL pgvector. Package: pl.km. Build: Gradle. Auth: OAuth2 Resource Server (JWT) via Keycloak realm `local-rag`, roles `rag_admin` (ingest) / `rag_user` (query). Query: pgvector over-fetches candidate pool, local cross-encoder reranker (ms-marco-MiniLM ONNX via onnxruntime) re-scores; score threshold applied to reranker output. Infra: docker-compose (pgvector/pgvector:pg16 + Keycloak + app image). Tests split: unit in `src/test` (`test` task); integration (`@WebMvcTest`+) in `src/integration-test` (`integrationTest` task, wired into `check`).
