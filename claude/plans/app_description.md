Spring Boot 3 app (Ports & Adapters). Ingests local files/docs via REST API, creates embeddings (Spring AI + OpenAI), stores to PostgreSQL pgvector. Package: pl.km. Build: Gradle. Auth: OAuth2 Resource Server (JWT) via Keycloak realm `local-rag`, roles `rag_admin` (ingest) / `rag_user` (query). Infra: docker-compose (pgvector/pgvector:pg16 + Keycloak + app image).
